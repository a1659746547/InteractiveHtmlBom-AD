如何更新数据与统计口径

当前是本地页面，数据不会自动刷新。后续可以从宝塔下载本站访问日志，点击「导入数据」，选择未压缩的 .log / .txt 文件；也可以导入本页面导出的汇总 JSON。日志在当前浏览器内处理，不上传到服务器。新导入的数据会替换当前数据，请导入完整的统计区间，避免重复拼接。

主页访问统计 GET / 或 /index.html 返回 200 / 304 的请求。过滤根据爬虫标识、同一 IP 的探测路径和测试出口进行，不代表已经准确识别所有真实访客。日志中没有 Host 字段，可能包含直接访问服务器 IP 的请求。

仅用于下一次导入，不会上传或保存。

统计快照只含每日汇总；筛选多个但非全部日期时，无法计算跨日期去重 IP 和响应状态分布，会显示「—」。导入原始日志后可以准确计算这些指标。汇总导出不含访问者 IP、原始请求路径或 PCB 数据。
