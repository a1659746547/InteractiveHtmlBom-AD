数据与统计说明

数据说明 · IP 数只用于观察访问趋势，仍可能包含伪装浏览器的机器人。使用计数与访问日志分别统计；使用计数不含 PCB 内容。失败原文件按页面告知暂存 1 小时。
统计口径与更新方式

服务器每 30 秒重新读取日志，页面每 60 秒更新，可点击「刷新数据」立即获取。日期筛选由服务器计算跨日去重 IP。IP 明细仅限登录后台查看，汇总导出仍不含 IP。

主页访问统计 GET / 或 /index.html 返回 200 / 304。根据爬虫标识、探测路径和测试出口过滤机器流量；过滤结果不等于确认的真实用户。服务器 IP 直访也可能计入，现有日志无法区分请求 Host。

估算地区由服务器本地 ip2region 地址库解析，不向第三方发送访客 IP。地区代表网络出口的大致位置，使用代理或 VPN 时可能不准确。共享出口的多个用户可能使用同一个 IP。

分享接口没有历史访问记录；解析次数和活跃时长从新版页面上线后统计，旧日志无法补回；使用计数不含 PCB 内容。失败排查样本按用户开始解析时的告知暂存 1 小时。
