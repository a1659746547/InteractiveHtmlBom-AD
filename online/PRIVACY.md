# 数据处理说明

解析和查看 PCB 的常规流程在浏览器本地执行。以下可选服务存在网络与服务器数据处理，部署者应据实向使用者说明。

| 功能 | 处理的数据 | 位置与边界 |
| --- | --- | --- |
| 本地 PCB / Gerber 查看 | 文件与解析结果 | 浏览器内存；进度可保存在浏览器本地存储 |
| 分享 | 设计数据和当前进度，可选访问密码 | 保存至分享服务；过期清理；已取得的副本无法撤回 |
| 图片反馈 | 用户填写的内容、联系方式和主动添加的图片 | 由反馈服务发送到部署者配置的邮箱 |
| 聊天室 | 消息及用户主动选择公开的进度或元件信息 | 聊天服务，不默认附带 PCB 原文件 |
| 使用统计 | 匿名使用事件及服务端网络访问信息 | 统计服务；IP 和活跃时长不等于真实人数或焊接时长 |
| 失败排查 | 失败元数据；符合限制时包括解析失败的原文件 | 供管理员分析；样本一小时到期，元数据按服务配置清理 |

当前同步的线上首页移除了上传区域的失败排查短提示，但相关处理逻辑仍在。公开源码中的文档不会把这一状态描述成“失败文件绝不上传”。自部署者应核对并提供适合自己的提示与隐私说明。

具体行为、请求限制和清理机制见 [FAILURE-RECORDS.md](FAILURE-RECORDS.md)、[SHARE-PASSWORD.md](SHARE-PASSWORD.md)、[PUBLIC-CHAT.md](PUBLIC-CHAT.md)、[USAGE-STATS.md](USAGE-STATS.md) 和 [FEEDBACK-SETUP.md](FEEDBACK-SETUP.md)。其中历史发布记录是实现背景，实际部署应以当前配置和代码为准。
